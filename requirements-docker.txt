# Phase 8 note: versions are pinned EXACTLY (not just lower-bounded),
# matching the environment that actually trained/pickled
# data/interim/phase6_model_bundle.pkl. This was not a hypothetical
# concern — the first real Docker build of this image (unpinned,
# `scikit-learn>=1.3`) pulled scikit-learn 1.9.0 while the bundle had been
# pickled with 1.8.0, and the container logged a real
# `InconsistentVersionWarning` at startup when unpickling the model's

# working by chance is exactly the kind of reproducibility gap this phase
# exists to close — pinning removes it rather than hoping future installs
# stay compatible.
